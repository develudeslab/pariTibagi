Nome do Projeto
  Pari Tibagi

Integrantes
  Lucas Kauan
  João Pedro
  Vitoria Louzada

Descrição
  Um jogo que busca resgatar a cultura do povo indígena Kaingang 
  tranzendo uma gameplay que mistura varios elementos culturais com minigames de modo ludico
  sendo um jogo educativo decolonial
  
Gênero do jogo
  Top down
  exploração
  
Público-alvo
  Estudantes do Ensino básico e médio

Tecnologias utilizadas
  Unity
  Audacity
  Pixelart

Istruções para abrir o projeto
  Baixar o projeto pelo Github, na unity hub em projetos clique em add e após em add project from disk e selecione
  a pasta que foi baixada e espere a unity abrir
